# রিপোর্ট বই — মাসিক পরিকল্পনা ও রিপোর্ট অ্যাপ

বাংলা ভাষায় মাসিক পরিকল্পনা, দৈনিক কাজের হিসাব এবং মাসিক রিপোর্ট তৈরির একটি মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপের প্রাথমিক সংস্করণ।

## এখন যা কাজ করে

- মাস নির্বাচন
- মাসিক পরিকল্পনার ফর্ম
- প্রতিদিনের কাজের হিসাব
- দৈনিক তথ্য থেকে মাসিক মোট হিসাব
- ড্যাশবোর্ডে অগ্রগতি ও সারাংশ
- ব্রাউজার থেকে PDF/প্রিন্ট
- JSON ব্যাকআপ ডাউনলোড এবং ব্যাকআপ পুনরুদ্ধার
- মোবাইল ও ডেস্কটপ উপযোগী বাংলা ইন্টারফেস

## চালানোর নিয়ম

এটি একটি static app; কোনো build command বা package install দরকার নেই।

1. `index.html` ফাইলটি ব্রাউজারে খুলুন, অথবা GitHub Pages দিয়ে প্রকাশ করুন।
2. GitHub repository-তে **Settings → Pages** খুলুন।
3. **Build and deployment** অংশে **Deploy from a branch** নির্বাচন করুন।
4. Branch হিসেবে `main` এবং folder হিসেবে `/(root)` নির্বাচন করে Save করুন।
5. প্রকাশ সম্পন্ন হলে GitHub Pages-এর দেখানো URL-এ অ্যাপ খুলুন।

## গুরুত্বপূর্ণ ডেটা নোট

বর্তমান সংস্করণে তথ্য ওই ব্রাউজারের `localStorage`-এ থাকে। অর্থাৎ একই ডিভাইস ও একই ব্রাউজারে আগের তথ্য দেখা যাবে; অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে সিঙ্ক হবে না। ব্রাউজারের ডেটা মুছে গেলে তথ্য হারাতে পারে, তাই **ডেটা ব্যাকআপ** থেকে নিয়মিত JSON ফাইল ডাউনলোড করে রাখুন।

এই সংস্করণে লগইন, অনলাইন ডেটাবেস, সদস্য-ভিত্তিক অ্যাকাউন্ট বা দায়িত্বশীলের আলাদা ড্যাশবোর্ড নেই। এগুলো পরবর্তী সংস্করণে যোগ করা যেতে পারে।

## পরবর্তী উন্নয়নের প্রস্তাব

- মূল কাগজের ফরমের প্রতিটি ঘর দায়িত্বশীলের সঙ্গে মিলিয়ে চূড়ান্ত করা
- সদস্যের লগইন এবং দায়িত্বশীলের অনুমোদিত রিপোর্ট দেখা
- নিরাপদ অনলাইন ডেটাবেস ও একাধিক ডিভাইসে সিঙ্ক
- মাসিক পরিকল্পনা বনাম বাস্তব কাজের বিস্তারিত তুলনা
- রিপোর্টে মন্তব্য, স্বাক্ষর এবং আরও নির্ভুল PDF layout
